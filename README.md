## Profesyonel Profil / Career Summary

Elektrik-Elektronik Mühendisliği lisans temeli üzerine Yapay Zeka yüksek lisansı ile uzmanlaşmış, gömülü donanım katmanından bulut tabanlı makine öğrenmesi dağıtımlarına kadar uçtan uca sistemler geliştiren Yapay Zeka Mühendisiyim. 

Gömülü sistemler (STM32, ESP32, Raspberry Pi) ve endüstriyel haberleşme protokolleri (CAN Bus) üzerinden veri toplama süreçlerinden başlayarak, büyük ölçekli veri analitiği (AWS S3, Athena), vektör tabanlı bilgi geri çağırma (Qdrant, Elasticsearch), büyük dil modelleri (LLM, RAG, ReAct Ajanları) ve gerçek zamanlı bilgisayarlı görü (YOLO, OpenCV, PaddleOCR) mimarilerini entegre eden yüksek performanslı çözümler tasarlıyorum.
